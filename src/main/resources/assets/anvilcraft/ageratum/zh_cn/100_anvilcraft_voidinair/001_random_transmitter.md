# <ref item="voidinair:random_transmitter"/>

<recipe id="voidinair:random_transmitter"/>

## 功能

- 每一面都能安装一个发信单元，同一方块空间内最多容纳六个
- 未通电时，每个发信单元每游戏刻都会在红石信号强度 0 和 15 之间随机切换
- 只能从未安装发信单元的一面输入红石信号
- 任意输入面收到信号时，所有输出都会关闭，直到输入信号消失

## 组装与调整

- 手持另一个<ref item="voidinair:random_transmitter"/>右击中央方块的空闲面，可增加一个输出
- 使用<ref item="anvilcraft:anvil_hammer"/>可以将已有发信单元移到其他面
- 潜行并用<ref item="anvilcraft:anvil_hammer"/>右击外侧的发信单元，可以将其拆下并回收
- 破坏整个方块时，会按已安装的发信单元数量返还物品
