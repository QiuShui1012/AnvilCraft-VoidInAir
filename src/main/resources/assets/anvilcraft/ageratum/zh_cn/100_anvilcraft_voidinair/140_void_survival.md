# <ref item="voidinair:totem_of_void"/>

<recipe id="voidinair:totem_of_void"/>

- 持有者受到足以致命的虚空伤害时触发
- 可以直接放在主手或副手，也可以装入生效的护符盒
- 清除现有效果，给予常规保命恢复效果和缓降效果，随后被消耗
- 将获救实体传送到主世界最大建筑高度，X 与 Z 坐标会按维度比例换算

# <ref item="voidinair:void_amulet"/>

虚空护符与其他[扩展护符](100_amulets.md)使用相同的获取和仿制方式。

- 生效时免疫虚空伤害
- 包含与虚空图腾相同的救援和恢复效果
- 死亡保护触发时不会被消耗

<info>
坐标按照正常的维度传送比例换算。例如从下界获救时，会先把 X 与 Z 换算为对应的主世界坐标，再执行传送。
</info>
