# 扩展护符

这些物品沿用铁砧工艺[护符](../006_prop/100_amulet.md)页面所述的获取与生效规则。要取得第一个护符，需要在生效的护符盒中放入不死图腾，再承受对应的致命伤害并存活；之后便可在珠宝加工台中仿制。

| 护符                                     | 致命伤害来源             | 效果                                       |
|:-----------------------------------------|:-------------------------|:-------------------------------------------|
| <ref item="voidinair:void_amulet"/>      | 虚空伤害                 | 免疫虚空伤害，并提供可重复使用的虚空救援   |
| <ref item="voidinair:snowflake_amulet"/> | 冻伤                     | 免疫冻伤，并能在细雪上行走                 |
| <ref item="voidinair:beehive_amulet"/>   | 蜜蜂                     | 蜜蜂会忽略佩戴者，可以安全采集蜂蜜与蜜脾   |
| <ref item="voidinair:gold_amulet"/>      | 猪灵或猪灵蛮兵           | 猪灵会将佩戴者视作穿着金质盔甲             |
| <ref item="voidinair:dolphin_amulet"/>   | 海豚、守卫者或远古守卫者 | 给予海豚的恩惠，并大幅缩短守卫者的索敌距离 |
| <ref item="voidinair:pumpkin_amulet"/>   | 末影人或嘎枝             | 相当于佩戴一个不可见的雕刻南瓜             |
