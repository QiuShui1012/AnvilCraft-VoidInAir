# <ref item="voidinair:random_transmitter"/>

<recipe id="voidinair:random_transmitter"/>

## Function

- Each face can hold one transmitter, allowing up to six transmitters in the same block space
- While unpowered, every installed transmitter randomly switches between redstone strengths 0 and 15 every game tick
- Redstone input is accepted only through a face without a transmitter
- A signal on any input face disables every output until the input signal is removed

## Assembly and Adjustment

- Place another <ref item="voidinair:random_transmitter"/> on a free face of the central block to add an output
- Use an <ref item="anvilcraft:anvil_hammer"/> to move an installed transmitter to another face
- Sneak-use an <ref item="anvilcraft:anvil_hammer"/> directly on an outer transmitter to remove and recover it
- Breaking the block returns one item for every installed transmitter
